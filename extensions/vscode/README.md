# Highlight ES|QL

Syntax highlighting for [ES|QL](https://www.elastic.co/guide/en/elasticsearch/reference/current/esql.html) (Elasticsearch Query Language) in Visual Studio Code.

## Features

- Highlighting for commands, functions, operators, literals, and parameters
- Comments, strings, numeric literals, time intervals, type casts
- Built-in support for the `.esql` file extension
