# ESQL Syntax

Syntax highlighting for [ES|QL](https://www.elastic.co/guide/en/elasticsearch/reference/current/esql.html) (Elasticsearch Query Language) for Visual Studio Code.

## Features

- Full syntax highlighting for ES|QL queries
- 43 commands (source, processing, header)
- 126 built-in functions
- Comments (`//`, `/* */`, `/** */`)
- Strings (double-quoted, triple-quoted, backtick-escaped)
- Query parameters (`?name`, `?1`, `?`)
- Type casts (`::integer`, `::keyword`)
- Time intervals (`5m`, `1hour`, `2days`)
- Numeric literals (integers, floats, scientific notation)
- Named operators (`AND`, `OR`, `NOT`, `IS`, `IN`, `LIKE`, `RLIKE`)

## File Association

Files with the `.esql` extension are automatically recognized.
